# Ziyo App — Prototype & KPI Dashboard

Live demos served via GitHub Pages.

## App Prototype

> iOS-style HTML/CSS/JS prototype of the Ziyo student-engagement platform.

🔗 **[Open Prototype](https://pankajbisht-1981.github.io/ziyo-prototype/Ziyo_App_Prototype.html)**

## KPI Dashboard

> Interactive impact-metrics dashboard tracking 25 KPIs across 5 layers — Reach, Engagement, Outcome, Operations, and North Star.

🔗 **[Open KPI Dashboard](https://pankajbisht-1981.github.io/ziyo-prototype/Ziyo_KPI_Dashboard.html)**

Layers:
| Layer | Focus |
|---|---|
| ⭐ North Star | Active beneficiaries — is the platform alive and growing? |
| 📡 Reach | How many users can we reach and convert? |
| 🎯 Engagement | Are users coming back and participating? |
| 🏆 Outcome | Did anything actually change in their lives? |
| ⚙️ Operations | Is the platform running reliably? |
